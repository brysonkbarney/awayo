# Contributing

Thanks for helping make Awayo better.

For now, keep changes small and focused. The project is early, so issues and pull requests that clarify the product are just as useful as code.

## Local Setup

```sh
swift build
swift run Awayo
Scripts/package_app.sh
```

## Product Principles

- Be honest about security. Privacy Cover is casual privacy. macOS Lock Screen is security.
- Prefer native macOS behavior over clever workarounds.
- Keep the app fast, quiet, and easy to quit.
- Make the fun parts optional.
